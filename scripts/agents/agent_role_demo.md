# Agent 角色示例：如何以 Agent 身份发起请求

此文档演示如何在本地使用一个简单示例，以“agent 角色”发起请求并记录对话提示（prompt）。

步骤：

1. 观察目标任务并准备上下文（项目文件、相关代码片段、期望输出）。
2. 准备一个简短、明确的系统提示，说明 agent 的身份与约束（例如：语言为中文、只修改特定文件夹、先输出 plan）。
3. 生成用户提示（自然语言），包含要完成的动作与验收标准。
4. 在本地运行示例脚本 `agent_role_example.js` 来查看提示模板。

示例系统提示（用于对话模型）：

> 你现在是 FoundryAuras 项目的 `Localization Agent`，你的任务是检查 `languages/` 文件夹的翻译键是否完整。请只输出 JSON 格式的结果，并给出缺失键的最小修复建议。

示例用户提示：

> 请比较 `languages/zh-CN.json` 与 `languages/en.json`，列出缺失的英文键以及缺失的中文键。仅列出键路径数组。

更多：参见 `agent_role_example.js`，它演示如何将上述提示模板打印或传递给本地的模型接口。
